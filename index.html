IPL Teams Analysis

SQL (Structured Query Language) is a language used to interact with a database. This case study uses SQL to examine a small database containing player acquisition data from the Indian Premier League (IPL), a comercially successful cricket league. In 2022 the IPL signed a media rights deal for 48,390 crores, which is about which is about 6.2 billion USD. Its value has increased to $20 billion in 2026.

This analysis was completed using RStudio IDE. The dataset is limited and composed of 228 observations of player level data.

Data Exploration

The dataset is limited to player level data points. The table in the database is composed of 6 variables; a player’s name, their cost (in crores), their type, acquisition method, the player’s role within their team, and their team’s name. These variables can be used to answer questions such as:

  • Which team spent the most on players?
  • Which roles attracted the highest spending?
  • Did teams spend more on Indian or overseas players?
  • How did auction, retention, and RTM spending compare?
  • How balanced was each team’s roster by player role?

We will query the database to answer these questions.

Which team spent the most on players?

SELECT Team, SUM(Price_in_cr) AS "Cost"
FROM IPLPlayers
GROUP BY Team
ORDER BY Cost DESC;

To better communicate with stakeholders, the SQL query tables are output as a variable and visualized using ggplot from the R Programming library.

A basic bar chart clearly depicts Lucknow Super Giants as the most costly team by a very small margin.

The plot is visually is readable but can be much improved. The bars are wide and because the team costs are close in numbers, the visualization blends together. We can modernize the bar for a more visually appealing plot and label the lines with the cost. This format considers the stakeholder that wants to see a simple overview as well as the stakeholders that would like to values.

ggplot(team_cost, mapping= aes(reorder(Team, Cost), Cost))+
  geom_segment(aes(xend= reorder(Team, Cost), yend= 0), linewidth = 0.4)+
  geom_label(aes(y= Cost-10, label = Cost), label.size= 0, fill= "white", size= 2)+
  geom_point()+
  coord_flip()+
  labs(title= "Indian Premier League: Total Cost by Team", x= NULL, y= "Cost (crores)")+
  theme_minimal(header_family = "Avenir")

In the more modernized plot, we can observe that Lucknow Super Giants spend 119.90 croles on player acquisitions, followed closely by Gujurat Titans.

Which are the highest priced players in each team?

To answer this question, we’ll create a temporary table to collect highest values in the Price_in_cr column. Then we’ll join the values using the Team column as primary key.

WITH Temp AS (
SELECT Team, MAX(Price_in_cr) AS Max_Price
FROM IPLPlayers
GROUP BY Team)

SELECT x.Team, x.Player, x.Role, x.Acquisition, x.Price_in_cr
FROM IPLPlayers AS x
JOIN Temp AS y
ON x.Team = y.Team
AND x.Price_in_cr= y.Max_Price
ORDER BY x.Price_in_cr DESC
